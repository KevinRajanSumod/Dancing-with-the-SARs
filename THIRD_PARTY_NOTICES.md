## Earth-observation data and services

- **NASA Earth science data and imagery:** NASA GIBS layers (NISAR browse imagery, OPERA Sentinel-1 RTC, MODIS reflectance), NASA FIRMS VIIRS thermal detections, NASA MCD64A1 burned-area maps, and NASA POWER climate values. NASA states that its Earth science data are open to everyone. Cite the relevant NASA mission/product and retain the source links in the app. This notice does not grant rights to NASA names, insignia, or other trademarks. [NASA Earth data access](https://science.nasa.gov/earth/data/).
- **geoBoundaries India ADM2, 2021:** source dataset `geoboundaries_ind_adm2_simplified.geojson`, release commit [`9469f09`](https://github.com/wmgeolab/geoBoundaries/tree/9469f09/releaseData/gbOpen/IND/ADM2). The dataset metadata reports source Pathways Data Pvt. Ltd./lgdirectory.gov.in and [Open Database License 1.0 (ODbL)](https://opendatacommons.org/licenses/odbl/1-0/). The project selects 52 Madhya Pradesh districts and dissolves those polygons for its state outline. The resulting district/state GeoJSONs are adapted ODbL data; preserve attribution and follow ODbL terms for redistributed derivative databases. [Dataset metadata](https://www.geoboundaries.org/api/current/gbOpen/IND/ADM2/).

## Software dependencies

`THIRD_PARTY_DEPENDENCIES.csv` lists the installed JavaScript packages and the direct Python packages used by the data scripts, with versions and license declarations found in their upstream package metadata when this inventory was generated. It includes JavaScript runtime and development packages. The license field is a pointer, not a substitute for the license text; each package's own terms control. `package.json` and `package-lock.json` define the JavaScript dependency graph. Python packages are installed separately; retain their upstream license notices in the environment used to run the scripts.
